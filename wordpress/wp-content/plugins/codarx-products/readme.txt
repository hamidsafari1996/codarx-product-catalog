Custom Product post type with categories, pricing, and stock management.

== Description ==

Codarx Products adds a Product custom post type with:

* Title
* Description (editor)
* Featured image
* Price
* Stock quantity
* Product Category taxonomy

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/codarx-products/`.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to Products in the admin menu to add products.
